# Home Experience

Canonical direction: mature ERN, not a generic landing page.

Home should feel like opening a window onto Earth:
- compact navigation;
- immediate photographic/current-view Hero;
- large destination identity;
- small factual/local-time context;
- Watch live / Watch Earth / My Earth / Explore / Next live;
- horizontal Choose a Window;
- no giant explanatory blocks below the fold.

Secondary systems live in focused surfaces. The Hero may use legitimate provider/current imagery only when rights and freshness rules allow; screenshots of the old interface are never production imagery.
