# ERN Release Gates

ERN is not public-release ready until all gates pass.

## Product
- Mature visual language restored without heavy stacked-page regression.
- Hero is immediate Earth, not a giant explanatory landing page.
- Watch Earth, Explore, My Earth, Living Atlas, Moments and ERN AI are discoverable.
- Multiple windows per destination work.

## Playback
- Every discovery surface opens the shared player in context.
- No forced scroll to Hero.
- Close returns to browsing position.
- Previous/Next, source and fullscreen work.
- Embed failure has a graceful provider fallback.

## Truth
- No UNKNOWN/OFFLINE source is labeled live.
- No prerecorded source is labeled live.
- Link-only permission is respected.
- Provider attribution visible.

## Quality
- Desktop/mobile tested.
- Keyboard Escape/arrow navigation tested.
- No browser screenshot used as production imagery.
- Primary live inventory has current health checks.

## Data
- Recovered source provenance retained.
- Source schema validates.
- Large catalog can remain Atlas-only until individually promotable.
