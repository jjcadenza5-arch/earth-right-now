# Source ranking

General registry ranking now includes source truthfulness/reliability, not only editorial scores.

Ranking signals:
- quality, freshness and moment;
- HEALTHY bonus;
- DEGRADED / UNKNOWN / OFFLINE penalties;
- inside-ERN playable bonus;
- current-check bonus and expired-check penalty.

This does not change strict Live Right Now eligibility. It improves ordering on broader surfaces so an unchecked historical source does not outrank a recently verified, equally interesting source merely because its old quality score was high.
