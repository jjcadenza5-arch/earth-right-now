# Client network state

Browser online/offline state describes the visitor's connection only. It does not mutate camera health, truth, permission or source verification.

When offline, ERN says that live sources **may not load**. It does not claim that saved Earth content is available unless a real cache/service-worker implementation guarantees that.

The network watcher is environment-safe and can be removed cleanly. No persistent banner is added to the canonical visual experience.
