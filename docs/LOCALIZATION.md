# Localization

ERN discovery should not depend on English-only naming.

The interface supports English, Thai, German, French, Spanish, Japanese and Chinese. Source/destination data may carry aliases in multiple scripts, and search normalization operates over aliases as well as canonical titles.

Earth-intent interpretation also recognizes a deliberately small multilingual vocabulary for high-value visitor meaning, beginning with **current/live-now** requests and **small/local place** discovery. This vocabulary is semantic routing only: it never upgrades a source's truth, currentness, permission or playback capability.

Source truth labels remain semantically fixed even when their visible wording is translated.
