# Interaction Model

Core rule: play where the visitor is.

- Source cards open the shared immersive/local player; they do not scroll to Hero.
- Choose a Window opens the destination choice surface.
- Closing the viewer preserves the browsing context.
- Left/Right navigate playback history.
- Escape closes.
- Slash focuses Earth search.
- R invokes Surprise Me when focus is not in a text field.
- Fullscreen is optional, never required for playback.
