# Hero visuals

The Hero may use a catalog thumbnail only when the catalog explicitly supplies a safe HTTP/HTTPS thumbnail URL.

ERN does not use browser screenshots, captured UI, or fabricated "live" imagery as production Hero media.

When no legitimate poster exists, the Hero falls back to restrained category atmosphere rather than pretending the generated background is a camera view.

This keeps the mature photographic direction available as source imagery is recovered while protecting source truth.
