# Current-window language

ERN no longer stamps every item in Live Right Now with the phrase "LIVE RIGHT NOW."

Per-source eyebrow language follows actual delivery:
- LIVE WINDOW — playable continuous current window;
- CURRENT IMAGE — refreshed/current image;
- CURRENT AT SOURCE — current/live provider handoff;
- PARTNER LIVE — partner current view;
- PREVIEW — preview.

The section may be called Live Right Now as a discovery concept, but each camera keeps its precise truth semantics.
