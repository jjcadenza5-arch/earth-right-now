# Inside-ERN playback expansion

ERN should increase legal inside-ERN playback because the immersive experience is stronger when visitors can remain inside ERN. Expansion is permission-led, not iframe-led.

A provider can be technically embeddable and still remain LINK_ONLY.

Promotion to inside-ERN playback requires:
1. current provider/media validation;
2. explicit reviewed embedding permission compatible with ERN;
3. an allowlisted HTTPS embed host;
4. attribution/provenance retained;
5. graceful provider fallback;
6. successful real provider playback evidence before publication.

The provider policy now has an explicit permission-escalation boundary. Unknown/public-agency/video-platform sources cannot be promoted to EMBED_ALLOWED merely because an iframe works. Reviewed providers such as CouchTourist still require the individual source record itself to carry EMBED_ALLOWED.

EarthCam-quality experience is a quality target, not a rights shortcut.
