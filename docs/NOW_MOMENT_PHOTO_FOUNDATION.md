# Phase L — Temporary Now Moment Photo Foundation

Phase L prepares the still-photo path only. It does not activate uploads.

## Hard policy
- still photos only; video remains disabled;
- JPEG, PNG and WebP only;
- source file maximum 5 MB;
- stored derivative maximum 1.5 MB;
- longest dimension maximum 1920 px;
- canonical ERN place required;
- no free text/caption field in the first activation;
- no precise coordinates in stored/public records;
- metadata must be stripped before storage;
- moderation approval required before any public display;
- public records expire after 45 minutes;
- automatic publication is forbidden;
- visitor media never upgrades camera LIVE/current truth or source health.

## Metadata boundary
The first server-side verifier rejects common EXIF/XMP/GPS-bearing JPEG markers plus PNG/WebP metadata chunks. Client-side re-encoding may reduce metadata, but server verification remains mandatory.

## Activation order
Structured Earth Signals activate first. Still-photo Now Moments may only activate later after their separate production manifest is fully evidenced. Video remains a later phase.
