# ERN truth language matrix

ERN separates **source existence/actionability** from **present currentness**.

A source can remain available to open while its current verification is stale. In that case ERN may say:
- Source
- Open source
- Available source
- Recheck due
- Current check not confirmed

It must not say:
- Live window
- Current at source
- Watch live
- Open current source
- Live video source checked by ERN

Present-tense live/current language requires the strict current-source gate: HEALTHY, known permission, CURRENT_CHECK and actionable playback.

Destination cards follow the same distinction. They can report available sources without claiming those sources are current. Viewer accessibility announcements also distinguish current sources from sources whose verification is due.

This matrix is shared product language, not decorative copy. It is part of ERN's source-truth system.
