## Publisher / site identity

**Site name:** Earth Right Now  
**URL:** https://earthrightnow.app  
**Tagline:** See before you go.

## Short description

Earth Right Now (ERN) is a travel-discovery website that helps visitors see current or live views of real places before they go. ERN curates livestreams, refreshed current images and verified source links, then helps visitors explore places through a Living Atlas and an ERN Guide.

## Longer description

Earth Right Now is an Earth-first travel discovery service. Visitors can explore current or live views from destinations around the world, search by place or mood, use a Living Atlas, and ask the ERN Guide for relevant places. Travel planning links appear only after the place-discovery experience. Commercial relationships never change ERN's Earth-view ranking, source truth, currentness or Guide source selection.
