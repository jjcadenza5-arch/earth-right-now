# External Live Experience

EXTERNAL LIVE is a first-class ERN source type, not a broken embed.

When provider rules or technical constraints require external viewing:
- button says Open current source / Open source;
- accessible label explains that the provider opens;
- ERN keeps attribution and source status visible before handoff;
- no fake player shell is shown;
- returning to ERN preserves the visitor's browsing context because the provider opens separately.
