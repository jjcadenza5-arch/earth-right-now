# Static App Boundaries

The current clean master is browser-first.

Available now:
- structured catalog browsing;
- permitted-source playback;
- search, filtering and ranking;
- local favorites, recent history and preferences;
- local validation/preparation of a camera-submission record.

Needs a deployment service later:
- storing business submissions;
- scheduled provider health checks;
- private credentials;
- affiliate transaction/account integrations.

The interface must distinguish local preparation from server-side completion.
