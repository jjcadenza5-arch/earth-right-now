# Watch Earth currentness

Watch Earth is a curated journey through Earth **now**, so it uses a stricter gate than broad Explore.

A Watch Earth source must be:
- a live/current truth type;
- HEALTHY;
- permission-known;
- CURRENT_CHECK;
- actionable under canonical playback policy.

There is no stale/UNKNOWN fallback disguised as a Watch Earth journey. If the verified current pool is empty, the visitor should be routed to broader Atlas/Explore rather than shown an old source under an "Earth now" experience.

Inside-ERN legal playback receives a modest ranking preference without overriding quality and moment value.
