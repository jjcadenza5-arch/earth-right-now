# Attribution truth

Provider attribution and source currentness are separate facts.

ERN media credits never imply **live** merely because a provider is named. Credits use **Current source** only when the source passes the strict current-source gate; otherwise they use the neutral **Source** label.

Attribution remains visible for legal/provenance reasons regardless of currentness. Currentness cannot erase provider credit, and provider credit cannot upgrade source truth.

External navigation uses only safe HTTP(S) URLs, noopener/noreferrer semantics and ephemeral hidden anchors that are removed after activation.
