# Destination Model

A destination is not the same thing as a camera.

One place may contain:
- several live video windows;
- a refreshed live image;
- an official external current-view page;
- a partner window;
- a non-live preview used only when clearly labeled.

ERN ranks destinations separately from individual sources. The visitor can discover the place first, then Choose a Window. This preserves the mature ERN idea that different camera views appeal to different visitors.
