# Manual affiliate placement integrity

ERN uses explicit commercial placements only.

## Contract

- Every public affiliate offer must reference an exact `partnerId`.
- That partner must exist in `data/affiliate-partners.json`, be enabled, verified and inside its ERN recheck window.
- Every public affiliate offer must itself have current verification evidence.
- Travelpayouts is a platform relationship, not blanket approval for its brands.
- Travelpayouts Drive automation stays disabled. ERN may use only deliberate links/widgets for programs actually available to the ERN Project.
- Affiliate/sponsored state never affects Earth-window truth, Guide selection, Watch Earth ordering or editorial ranking.

The release preflight fails closed if these boundaries are violated.
