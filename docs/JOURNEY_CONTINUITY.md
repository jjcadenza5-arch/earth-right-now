# Journey continuity

ERN's mature experience is a journey through Earth, not a sequence of unrelated page loads.

## Watch Earth
- uses only strict-current actionable sources;
- uses the same shared player;
- advances sequentially with a timeout, not overlapping intervals;
- suspends advancement while the browser tab is hidden;
- resumes with the same configured pace;
- stores the visitor's current journey index/source in session memory;
- does not manufacture a new history item when media falls back.

## Hero
Hero rotation remains current-first, then prefers legal inside-ERN playback within the current pool. Daylight is a presentation preference, never permission to promote stale content.

## Surprise Me
Surprise remains playful but draws from strict-current inventory when available and prefers legal inside-ERN playback. Injected random values are bounded so test/custom callers cannot produce an invalid array index.

These rules keep ERN feeling alive without allowing motion, randomness or daylight to outrank truth.
