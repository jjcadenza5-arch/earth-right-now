# Place window selection

A place's preferred window is a convenience choice, not a raw quality contest.

Selection order:
1. discard sources that are not discoverable/actionable;
2. prefer sources that satisfy ERN's strict current-source gate;
3. prefer inside-ERN PLAY capability;
4. use the shared source score only after those gates.

This prevents a beautiful but stale or unavailable source from becoming a destination's default window merely because its quality/moment metadata is high.

The Living Atlas may remain broader than Watch Earth, but OFFLINE/UNAVAILABLE records are not presented as actionable Atlas results. The Live/current Atlas filter additionally requires known permission and CURRENT_CHECK.
