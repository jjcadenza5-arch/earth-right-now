# ERN stable-beta handoff — 23 September 2026

This file exists so future work does not restart or narrow ERN to one feature.

## Product identity
Earth Right Now — **See before you go.**

ERN is the whole system working together:
- Watch Earth / curated current windows
- Search / Explore
- Living Atlas
- Local Earth / small-place discovery
- ERN Guide as the tour-guide doorway, not a generic chatbot
- My Earth
- Now Moments / Earth Signals
- camera-owner and place participation
- reviewed small-business/local-place discovery
- destination pages and shareable discovery
- See → Decide → Go business/travel bridge
- truthful LIVE VIDEO / LIVE IMAGE / EXTERNAL LIVE / PARTNER / PREVIEW labels

The **Crispy Pork Skin Strategy** remains a core design principle: small, lightweight, high-effect layers can make the whole experience more memorable, human and lovable without turning ERN into a heavy feature collection.

## Do not rebuild these
Do not replace working surfaces with a new architecture merely to refactor or polish. Fix observed visitor problems in place. Preserve Git history and the whole-product deployment guard.

## Stable-beta completion posture
The core public product is present. Remaining work should close a real release gate, improve source/map coverage, or fix a verified visitor problem.

Heavy backend activation comes after stable beta:
- real generative ERN AI backend
- real camera/place submission transport
- real Now Moment photo/video uploads
- moderation / abuse-reporting / TTL deletion pipeline
- reviewed business inventory
- affiliate/partner activation
