# ERN AI

ERN AI is a discovery layer over the same verified Earth registry. It is not a separate source of truth.

Initial intent examples:
- "show me wildlife"
- "quiet beach"
- "city with people"
- "volcano happening now"
- "beautiful place at sunrise"

ERN AI ranks/filter sources and hands the selected source ID to the shared PlaybackController. It cannot override truth, permission, health or promotion policy.
