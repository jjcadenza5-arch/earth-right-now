# Hero empty/current-check state

The Hero must never fall back from its strict verified-current pool into a merely available catalog row.

If no Hero-eligible source exists:
- location identity becomes the neutral Earth Right Now state;
- copy explains that current windows are being rechecked;
- Watch live and Next live are disabled;
- Explore, My Earth and Atlas remain available;
- Watch Earth remains available only if its own strict current journey has entries;
- no stale/UNKNOWN source is promoted visually just to avoid an empty Hero.

This is preferable to making the Hero look alive with a source ERN cannot currently stand behind.
