# Earth Signal contribution contract

The first contribution mode is intentionally structured and ephemeral. A visitor may select an approved signal type for a known ERN place. Free-text comments, usernames, profiles, direct messages and public precise coordinates are outside this phase.

Location is optional. **Near this place ✓** requires explicit location permission plus a successful near-place check. Without both, the observation remains location-unverified. Public signal records never expose the contributor's coordinates.

Submission transport is disabled until ERN has real abuse controls, rate limits, moderation/reporting, expiry/deletion infrastructure and an updated privacy notice. The client may form a local draft, but it must not pretend the draft was submitted.
