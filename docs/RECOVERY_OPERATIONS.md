# Recovery Operations

Large legacy catalog restoration is deliberately two-speed:

1. **Recover knowledge quickly** into quarantine candidate files.
2. **Promote slowly** after current health, permission and duplicate checks.

Priority goes first to historical embed candidates because they can restore the immersive ERN experience when current permission still exists. Official link-only destination pages can then be revalidated in batches.

No recovery batch changes Live Right Now until its records pass current policy.
