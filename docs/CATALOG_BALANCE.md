# Catalog balance

ERN should not optimize recovery for raw source count.

The coverage model measures:
- countries and regions represented;
- category distribution;
- truth-mode distribution;
- inside-ERN playback versus external provider handoff.

The recovery-needs helper can flag structural weaknesses such as too little inside-ERN playback or narrow geography. This supports the product rule "quality over quantity" while still preventing the curated network from becoming accidentally dominated by one provider, country or mountain-camera category.

Current recovery strategy should increasingly prioritize high-quality EMBED_ALLOWED / PARTNER sources and underrepresented categories once the official-link foundation is broad enough.
