# Viewer keyboard scope

Left/right arrows are viewer-history controls only while the immersive viewer is open.

Outside the viewer:
- arrows remain normal browser/page controls;
- R may invoke Surprise Me;
- / may focus search.

Inside editable fields, ERN does not hijack navigation keys. Escape blurs the active field rather than unexpectedly closing another surface.

This prevents global shortcuts from making the rest of the site feel trapped by the player.
