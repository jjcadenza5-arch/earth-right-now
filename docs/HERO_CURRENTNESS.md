# Hero currentness

The Hero is ERN's strongest "Earth right now" claim and therefore has stricter eligibility than general discovery.

A Hero source must now be:
- HEALTHY;
- currently checked;
- a genuine current/live truth type;
- permitted;
- actionable.

When both are available, inside-ERN playable windows are ordered before external handoffs. This makes the Hero feel like ERN rather than a directory while preserving honest external sources as secondary Hero candidates.

UNKNOWN, stale and expired sources can remain discoverable in appropriate surfaces but cannot become the primary Hero window.
