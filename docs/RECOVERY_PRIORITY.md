# Recovery priority

ERN recovery is no longer "next historical row wins."

Priority increases for:
- explicit legal inside-ERN playback, especially while inside-player coverage is low;
- underrepresented high-value travel categories such as coast/water, wildlife, cities and seasonal/farm conditions;
- countries with little current catalog representation;
- categories with low current coverage.

This deliberately resists rebuilding a catalog dominated by whichever mountain-webcam records happened to be easiest to recover.
