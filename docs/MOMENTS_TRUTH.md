# Editorial Moments truth

"Beautiful Earth", "Interesting Earth" and "Useful Earth" are editorial classifications and may use the broader discoverable pool with truthful source badges.

"Earth Happening Now" is different: the phrase itself asserts currentness. It therefore requires HEALTHY + known permission + CURRENT_CHECK + a live/current truth type.

A stale source may remain a beautiful or interesting destination, but it cannot retain a Happening Now presentation merely because an old category tag says so.
