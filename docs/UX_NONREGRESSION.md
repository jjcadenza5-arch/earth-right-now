# UX Non-Regression Checks

Before any ERN release:
- Camera/source card click opens playback in current context; it never scrolls to Hero.
- Hero can open the same shared player, but does not own a duplicate engine.
- Viewer Close returns visitor to the place they were browsing.
- Previous/Next work without page navigation.
- Full screen is optional, never required.
- Watch Earth is a curated journey, not a giant list.
- Living Atlas can expose a broader catalog including temporarily unavailable/current-check sources with truthful labels.
- My Earth persists locally.
- Multiple windows can coexist for a destination.
- No source with health UNKNOWN/OFFLINE appears as LIVE.
- PREVIEW is never styled/labeled LIVE.
- Link-only sources open provider rather than being restreamed.
- Mobile horizontal window browsing does not create long vertical stacks.
- Major mature surfaces remain discoverable without filling the homepage with giant sections.
