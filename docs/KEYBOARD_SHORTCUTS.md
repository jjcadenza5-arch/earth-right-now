# Keyboard shortcuts

ERN shortcuts are scoped so they do not fight the browser or text entry.

- Escape closes the viewer, or blurs an active editable field.
- Left/Right navigate only while the immersive viewer is open.
- R triggers Surprise only outside the viewer.
- / focuses Earth search without scrolling.
- Cmd/Ctrl/Alt-modified keystrokes are left to the browser/OS.
- Already-prevented keyboard events are ignored.

This keeps keyboard navigation useful without hijacking common browser shortcuts.
