# Curation invariants

ERN now uses the same core eligibility functions across Hero, Choose a Window, Watch Earth, Moments, Explore and Living Atlas.

The ordering principle is consistent:
1. truth/actionability gate;
2. strict currentness where the surface promises current Earth;
3. legal inside-ERN playback preference where useful;
4. quality, moment and editorial ranking;
5. diversity/rotation.

Quality can reorder eligible sources; it cannot make an ineligible source current.

Choose a Window prefers strict-current sources before playback convenience and quality. This preserves visitor choice while making the first options the most trustworthy.

Earth Happening Now delegates currentness to the shared current-source gate rather than maintaining a parallel interpretation.

Hero primary action copy comes from the same playback capability used elsewhere, preventing a separate Hero label from drifting away from source truth.
