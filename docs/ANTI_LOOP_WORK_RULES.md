# ERN Anti-Loop Work Rules

Updated: 2026-09-25

ERN work must advance from state, not from repetition. A completed, blocked, failed, or sufficiently researched item is not automatically "next work."

## Terminal / hold states

### Provider discovery
- When all current external providers are classified, state is `CURRENT_CATALOG_RESEARCH_COMPLETE`.
- Next action is `HOLD_UNTIL_EXTERNAL_CATALOG_CHANGES`.
- Do not reopen already classified provider families just because their public pages remain reachable.

### Provider-generated targets
- KitzSki and Skyline interactive generators remain blocked until exact official generated code is obtained.
- IMO Reykjavík remains blocked until an exact stable authorized current-image URL is identified.
- Recorded extraction blockers prevent repeated machine retrieval attempts through the same failed route.
- Do not guess embed code, iframe URLs, image assets, or provider endpoints.

### Failed playback
- A deployed HUMAN_PLAYBACK failure is not recycled into the primary review lane.
- Retest only after a material target/provider change or an explicit justified re-review.
- A newer playback failure supersedes an older success for current-proof purposes.

### LIVE HERE renewals
- Human review remains mandatory.
- Only the minimum number of due/expired renewals needed to preserve the target-ready count become primary work.
- Extra renewal debt remains backlog instead of forcing unnecessary review.

### Commercial breadth
- **Pilot breadth stop:** once private research reaches 30 distinct places, new-destination research goes on hold by default until an explicit commercial decision or material catalog change.
- Places with existing private real-option research are excluded from new-destination research.
- Sources marked `travelResearchEligible:false` are excluded entirely from travel onboarding.
- Example: ISS / Low Earth Orbit is an Earth-view experience, not a normal "before you go" travel destination.

### Commercial depth
- Default target is two distinct researched travel intents per place.
- Once a place has two intent types, depth research stops unless explicitly reopened later.
- Do not fill every possible intent category simply because the schema supports it.
- Research is private and never implies affiliate relationship, sponsorship, demand, revenue, public activation, or ranking priority.

## No duplicate presentation

Operations should not list the same provider preparation in both:
- provider-generated target staging, and
- family-level preparation.

If an exact-target registry entry already exists, that target registry is the authoritative next-work surface.

## General rule

Before starting a task, ask:

1. Is this genuinely unresolved?
2. Has this exact item already been researched, reviewed, failed, or blocked?
3. Has anything material changed since the last result?
4. Does this work improve visitor value, safety, truth, reliability, or a defined business-readiness gap?
5. Is there a finite stopping condition?

If the answer does not justify new work, hold the item and move to another queue.

**ERN should improve continuously, but it should not move in circles.**
