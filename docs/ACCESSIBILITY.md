# Accessibility Baseline

- Semantic buttons/links for actions.
- Viewer keyboard Escape, Previous and Next.
- Focus containment in immersive viewer.
- Fullscreen is optional.
- Source/provider remains reachable without fullscreen.
- Respect reduced-motion preference.
- Current-image alt text uses destination title.
- Truth labels are text, never color-only.
- Mobile controls remain reachable above safe-area inset.
