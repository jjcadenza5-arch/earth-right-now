# Choose a Window

Choose a Window is a compact horizontal Earth strip, not a second Explore grid.

Each choice:
- shows truthful source state;
- keeps enough destination identity to orient the visitor;
- selects locally/immersively without scrolling to Hero;
- can coexist with several views of one destination;
- never upgrades UNKNOWN into LIVE for visual appeal.

The strip should feel fast and visual. Detailed source diagnostics belong elsewhere.
