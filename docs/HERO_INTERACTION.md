# Hero Interaction

Hero is the front window onto Earth.

Actions must reflect actual capability:
- Watch live becomes Open current source for LINK_ONLY material.
- Watch Earth is disabled/redirected when no curated verified journey exists.
- My Earth and Explore open focused surfaces.
- Next live changes the Hero selection only; it does not launch playback.
- Hero source status remains visible and truthful.

The Hero is visually dominant, but it does not own playback. Playback remains shared and can originate anywhere.
