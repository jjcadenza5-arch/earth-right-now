# Living Atlas

Living Atlas is the broad network, not the same thing as Live Right Now.

It may contain:
- healthy promotable live sources;
- official external current-view pages;
- sources being rechecked;
- temporarily degraded/offline records when useful for provenance and future recovery;
- clearly labeled previews.

As the catalog grows, Atlas uses clustering/filtering rather than creating one DOM/media object per camera. Selecting a point still hands a source ID to the shared playback controller.
