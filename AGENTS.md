# ERN Agent Instructions

Before changing ERN:
1. Read docs/CONTINUITY.md.
2. Read docs/ERN_PRINCIPLES.md.
3. Read docs/SOURCE_TRUTH_MODEL.md.
4. Read docs/ARCHITECTURE.md.
5. Read docs/BUILD_STATE.md.

Never redesign ERN merely to solve a technical problem. Preserve mature product behavior and repair the implementation.

After meaningful work, update docs/BUILD_STATE.md and docs/CHANGELOG.md.

Never label prerecorded media LIVE. Never force a visitor to scroll to Hero to play a selected source.
